# HelperBot

Telegram-бот для заявок о процессах, которые отнимают время у команды.

## Что делает

- Сотрудник указывает имя и проблему. Часы за неделю и идею улучшения можно пропустить.
- Перед отправкой поля можно исправить. Черновик сохраняется в PostgreSQL и переживает перезапуск.
- Администратор получает заявку, видит очередь новых и меняет статус: новая, в работе, готово, не берём.
- Автор получает сообщение о смене статуса и видит последние 10 заявок через `/my`.
- Интерфейс работает в личном чате с ботом. Доступ к административным действиям проверяется по Telegram ID.

## Запуск на Windows

Нужен Python 3.12 и PostgreSQL. В `.env` задайте `TOKEN`, `DATABASE_URL`, `ADMIN` (числовой Telegram ID). Файл уже предусмотрен и не попадает в Git.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\helperbot.exe
```

Администратор должен открыть личный чат с ботом и отправить `/start`, чтобы получать уведомления. Бот работает через long polling; одновременно запускайте только один экземпляр с этим токеном. Таблицы `helperbot_drafts` и `helperbot_ideas` создаются при первом запуске.

## Docker

```powershell
docker build -t helperbot .
docker run --rm --env-file .env helperbot
```

Для постоянной работы запустите контейнер на машине, которая всегда включена, с политикой перезапуска вашего окружения.

## Команды

`/start` — меню; `/new` — новая заявка; `/my` — мои заявки; `/cancel` — удалить черновик; `/help` — подсказка. Администратору доступны `/inbox` и `/stats`.
